# 沿途 · 景点讲解

独立的中文旅游讲解项目。手机上打开后，可手动选景点，或在室外开启定位到点提示；可听文字讲解、语音提问、收藏，以及选填照片提问。馆内展品由用户手动选择，避免用 GPS 猜测展柜。

## 当前进度

- 长沙试运行版收录五一广场、太平街、贾谊故居与长怀井、火宫殿、黄兴南路、杜甫江阁、橘子洲、爱晚亭与马王堆陈列。每处提供简短介绍、深入故事、现场寻找提示及资料来源；市区新增点位坐标来自高德地点页，橘子洲雕塑使用开放地图近似坐标，景点正文依据省级文旅资料。
- 选目的地可打开高德步行路线；“附近有什么”在定位精度足够时列出已收录地点的直线距离。湘菜正餐、夜景、演出入口打开高德实时搜索，店铺营业与演出安排不写死。
- 景点正文无需 AI 接口；未配置接口时仍能问已收录的历史、现场线索、附近与路线，无法核实的问题明确说不知道。照片问答只在配置兼容 OpenAI `chat/completions` 的服务后显示。
- 手机浏览器的语音识别和朗读取决于浏览器与系统支持；到点提示只在页面活跃时运行。PWA **不能保证锁屏或后台连续讲解**。室内展柜和岔路无法仅凭 GPS 可靠辨认；逐转向导航由地图应用负责，用户以现场路牌为准。
- `npm run build:static` 生成可发布到 HTTPS 静态站点的 `dist/`。静态站点可用景点讲解、定位、朗读和收藏；AI 追问需部署服务端并配置接口。

## 本地运行

需要 Node.js 20 或更高，无需安装依赖：

```bash
node server.js
```

访问 `http://localhost:3000`。手机访问需要 HTTPS 站点（浏览器定位和安装 PWA 通常要求安全上下文）；电脑上的 localhost 可直接测试。`npm test` 检查坐标匹配及问答 API 边界。

## Android APK

`android/` 是独立的 Android 原生工程，桌面名称为“沿途”，应用 ID 为 `com.yantu.guide`，最低 Android 8.0。它内置长沙讲解、景点与文物手动选择、中文系统朗读和音色语速选项、收藏、有限的离线语音提问，以及有通知提示的前台到点定位服务；锁屏时服务可继续运行，用户须从可见界面主动开启。选目的地或说“我要去五一广场”会打开高德步行路线。没有 AI 接口时，不会对资料以外的问题编造答案。

GitHub Actions 的 **Build Android APK** 工作流在 Android 代码更新时构建调试版 APK，文件在对应运行记录的 Artifacts 中。调试版适合个人安装试用，发布给其他用户前还需要正式签名、设备实测和内容扩充。本地有 Android SDK 与 Gradle 8.9 时可在 `android/` 执行 `gradle :app:assembleDebug`。

## AI 接口（可选）

在服务端设置 `AI_API_BASE_URL`（以 `/v1/` 结尾的兼容地址）、`AI_API_KEY`、`AI_MODEL`。请勿把密钥写进网页、仓库或提交 `.env`。例：

```bash
AI_API_BASE_URL=https://your-provider.example/v1/ AI_API_KEY=... AI_MODEL=... node server.js
```

服务端只向选定的服务商发送用户问题、当前地点资料及主动选择的照片。照片必须小于 4 MB。兼容接口的具体视觉支持取决于所选模型；如果模型不支持图片，服务端会返回错误。生产环境还需加用户鉴权、限流与费用上限。

## 加入景点

在 `data/places.js` 增加名称、`intro`、`story`、`lookFor` 与出处链接。室外点提供坐标及半径（`gcj` 为高德 GCJ-02，`wgs` 为 WGS84）；室内点提供 `artifacts` 列表供用户手动选择。坐标只是区域提示，不能推断某条巷子的转向或具体石碑上的痕迹。
